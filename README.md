# しまい場所ノート

「どこに置いたっけ？」をなくすための、置き場所の記録アプリです。単一HTMLファイルで動き、記録は使う人の端末の中にだけ保存されます（サーバーには送られません）。

## 使い方

1. **記録する**：ホームの大きなマイクボタンを押して、「パスポート、書斎の引き出しに入れたよ」のようにつぶやくだけ。内容の確認画面で直してから記録できます。声が使えないときは「文字で記録」からどうぞ。場所の写真も付けられます
2. **探す**：ものの名前でも、「旅行に使う充電するもの」のような曖昧な聞き方でも、声でも文字でも探せます
3. **記録を見る**：最近置いたもの、そろそろ確認したいもの（しばらく動かしていない記録）、すべての記録を大きな文字で確認できます
4. **データの管理**：記録の書き出し・読み込みができます。機種変更の前に書き出しておくと安心です

## プライバシー

- 記録は、お使いの端末のブラウザの中にだけ保存されます。外部へ送信されることはありません（声の聞き取りには、端末の音声認識の仕組みを使います）
- ブラウザのデータを消すと記録も消えます。大事な記録は「データの管理」から書き出して保管してください

## 技術メモ

- 単一HTML（`index.html`）＋アイコン＋ `manifest.json` のみ。ビルド不要で、GitHub Pages など静的ホスティングでそのまま動きます
- 保存形式（localStorage キー `find-it-items-v1` の配列）は、以前のサーバー版（Next.js）と互換です。同じアドレスで配信すれば、以前の記録がそのまま読み込まれます
